# 白子无人机技能

对应项目中的 `BANW_Special_Shiroko`，技能配置在 `1.6/Defs/SpecialSkills/Shiroko.xml`，现有游戏内标签为“黑子”。

## 武器普攻追击

EX无人机存在期间，白子的主武器每成功发射一发，就安排一次 `droneAttack`。无人机使用本发武器的瞄准对象，与白子弹丸的实际落点和伤害结果无关。

白子射偏、被闪避、被护甲完全减伤或被护盾吸收，均不会取消无人机追击。无人机不会等待白子的弹丸命中，自己射击也不会递归触发追击。没有实际射出子弹、没有有效敌方对象时不触发。

无人机的实体弹丸瞄准锁定目标，命中后独立经过闪避、护盾和护甲判定。追击必定触发不代表伤害绕过目标防御。

## 普通技能的20发连射

沿用每30秒自动选择敌人的规则，优先选择白子当前攻击对象，其次为25格内最近的可见敌人。

宿主执行 `normalAttack`，默认攻击力400%的单发技能伤害。无人机处于EX有效期时，同时锁定该目标执行 `burstAttack`：20发、每发间隔6 tick，即0.1秒。目标引用在整轮期间固定，白子切换攻击对象或停止普攻不会使无人机改射其他对象。

已开始的连射会在EX到期后继续完成，无人机保持显示到最后一发发射完毕；到期后不再接收新的宿主普攻追击。目标死亡、消失或离图，以及白子死亡或离图时停止剩余发射。

## 伤害与表现配置

| 参数 | 作用 |
| --- | --- |
| `droneAttack.attackPowerRatio` | 普攻追击总倍率，默认0.5，单发为普攻基准的50% |
| `burstAttack.attackPowerRatio` | 锁定连射总倍率，默认10 |
| `burstAttack.shots` | 连射次数，默认20；总倍率按此次数均分 |
| `burstAttack.shotIntervalTicks` | 逐发间隔，默认6 tick |
| 两段的 `penetration` | 各段独立护甲穿透，0.5表示50% |
| 两段的 `shotSound` | 每次实际发射时播放的音效 |
| 两段的 `projectileDef` | 无人机实体弹丸 |
| 两段的 `effecterDef` | 弹丸命中特效 |
| `droneTexturePath` | 跟随机体贴图；留空沿用项目简易机体 |
| `droneDrawSize` / `droneOffset` | 机体尺寸与相对白子的偏移 |

无人机使用 `isNormalAttack=true`、`isExSkill=false`。BA模式下读取白子的攻击属性、普攻倍率、基础精通、暴击和克制；每轮安排时保存白子的属性快照，每发命中独立判定暴击、闪避及防御。无人机伤害不会读取EX增益。

关闭 `useBattleStats` 时沿用项目独立基数模式，以 `basePower` 乘逐发倍率，不应用BA输出属性。默认两段均开启BA模式。

`ShirokoEffects.xml` 中的 `BANW_Shiroko_DroneShot` 复用现有 `Weapon/AR/AR_At` 音频素材，并允许多发声音重叠。可以分别替换两个伤害段的 `shotSound`；不会只在整轮开始时播放一次。
