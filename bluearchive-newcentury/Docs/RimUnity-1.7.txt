BlueArchive-NewWorld / RimUnity 1.7 配置

加载配置
仅支持 RimWorld 1.7，加载根目录语音、Common 和 1.7。
依赖 Harmony、RimUnity、ChezhouLib、HAR 的对应版本及 Royalty。
RimUnity 必须在本模组和 ChezhouLib 之前。模组程序集只保留 BANWlLib、MuiceLib 和 Newtonsoft.Json。
Spine 渲染由 RimUnity.Spine 提供，公告由 BANWlLib.Announcements.UpdateAnnouncementDef 处理。

资源路径
1.7/Data/RimUnity/catalog.json 是预制体、材质、Shader、Spine 等资源的运行入口。
普通 Def 引用的角色、建筑、武器、弹丸和图标贴图由 Common/Textures 与 1.7/Textures 提供，保持原版 ContentFinder 路径。
Common/UIAssets 保留仍需直接读取的界面散图。
Tools/Build/Sync-GameTextures.ps1 读取 UnityProject/Assets/Data/Archive.NewWorld/Textures，向 1.7/Textures 同步普通贴图；Common 中已有的图片不重复复制。
Prefabs：界面和伤害数字预制体；Atlases/card：抽卡图集；Sprites/Cost：COST 数字。
UIImage：学生立绘、头像和图标，保留原图片索引与闲置释放策略。
Effects：战斗特效图片，由 RimUnity 加载后交给原版材质绘制。
Spine 图集、骨骼数据、字体、视频、音频、材质和 GLSL 随标准清单导出。
主界面与抽卡根画布使用独立 UI 相机，保留粒子所需的顶点流。

构建
Tools/Build/Build-1.7.ps1 编译 BANWlLib 和 MuiceLib 到 1.7/Assemblies。
定义、补丁、语言与 UI 配置直接在 1.7 目录维护，构建不覆盖这些文件。
主库的 Newtonsoft.Json 引用来自 Source/References，不依赖其他版本目录。
构建仅需要已编译的 RimUnity 与 ChezhouLib 对应程序集，不自动重编译依赖或启动游戏。

导出工具
Tools/Build/BAUiRimUnityProbe.cs 维护主界面工程的导出流程；UIExportAssets.txt 保存源资源路径，不依赖运行时资源包的 manifest。
Tools/Build/BAImageRimUnityExport.cs 读取 1.7/UI/images/bundles.xml，维护图片工程的 RimUnity 导出流程。
两者调用 RimUnity PrefabExporter；BAAssetPublish 使用 ExportStorage.CopyForPublish 整理并合并清单。
后台导出需要图形设备读回贴图，不使用 -nographics。
导出先写入暂存目录，检查后再更新模组的 1.7/Data/RimUnity。
这些工具的维护副本位于模组 Tools/Build；Unity 工程内的现有文件保持原样。其旧资源包构建按钮不作为当前模组的发布入口。

离线无损整理
先复制About、Common/Textures、Common/UIAssets、1.7/Textures和1.7/Data/RimUnity到模组暂存副本。
用Python运行Tools/Build/Optimize-PngStorage.py，并传入该副本目录。工具只重压PNG的IDAT，逐张核对解压数据；保留尺寸、像素、扫描线过滤、透明度与颜色元数据，不修改视频和声音。
需要继续无损缩小时，在同一命令后添加--oxipng及oxipng可执行文件的路径；该模式需要Pillow，使用oxipng的4级压缩并禁止改变图像格式，只重选扫描线过滤和压缩方式。逐张核对像素（包括全透明像素的颜色），原样保留所有非IDAT块，仅采用体积更小的结果。oxipng与Pillow只用于离线整理，不随模组发布。
随后使用RimUnity的Tools/ResourcePacker处理暂存副本，重新生成载荷哈希、移除未引用载荷，并将有收益的GPU纹理保存为.rutex.gz。
ResourcePacker的两个位置参数依次为新输出目录、暂存模组根目录。输出中的Archive.NewWorld/1.7/Data/RimUnity用于替换暂存副本的同目录；同时保留PNG优化后的普通贴图与UI散图。
完成核对后再将资源同步回模组并部署。不要直接部署尚未经过ResourcePacker整理的RimUnity散列目录。
压缩后的发布资源需要RimUnity 0.1.8或更新版本；当前配套运行时为0.1.17。纹理GPU块和分辨率不变，只减少磁盘文件体积，不代表游戏显存占用同比下降。
