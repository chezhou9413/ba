# 2026-07-02 战斗系统修复与字段迁移记录

## 投射物主伤害上下文修复

原版 `Bullet.Impact` 会先执行 `base.Impact`，投射物在这个阶段被销毁后，旧的清理逻辑会提前移除 `ProjectileBattleContext`。

结果是主弹读取 `DamageAmount` 时无法拿到战斗上下文，主弹伤害没有进入统一伤害公式，而多段追加伤害因为提前保存了状态，所以看起来只有追加段吃到了伤害加成。

处理方式：

- 投射物进入命中流程后，销毁阶段不再立刻清理上下文。
- `Bullet.Impact` 结束后再清理上下文。
- `BattleProjectileExtension` 增加 `alwaysCrit` 字段，并传入 `BattleDamageRequest`。

## 旧暴击配置重新接入统一公式

`FontDef` 中的旧配置字段：

- `DisableCritical`
- `EnsureCritical`
- `DisableIncomingDamageFactorCritical`

之前只在旧的 `Pawn.PreApplyDamage` 分支里生效，新统一伤害公式和技能投射物会绕过这段逻辑。

处理方式：

- 新增 `DamageFontRuleUtility` 统一读取旧暴击配置。
- `BattleStatUtility.BuildDamageResult` 进入暴击计算前读取 `DisableCritical` 和 `EnsureCritical`。
- `DamageReductionComp` 在承伤系数计算前读取 `DisableIncomingDamageFactorCritical`。
- 公式调试日志显示应用配置后的有效强制暴击状态。

## 伤害飘字统一显示真实伤害

之前 `alwaysShowCriticalText` 会把公式阶段的伤害值缓存起来用于飘字。这个数值没有经过护甲、部位减伤和承伤系数，可能与实际造成伤害不一致。

处理方式：

- 删除固定公式伤害飘字队列。
- 伤害飘字统一从 `Pawn.PostApplyDamage` 的 `totalDamageDealt` 读取数值。
- `CriticalObjPool` 只保留普通暴击伤害显示入口，避免公式值绕过实际伤害流程。

## triggerHediff 字段统一

旧配置中存在拼写错误字段 `tiggerHediff` 和 `TiggerHediff`。本次迁移统一使用正确字段：

```xml
<triggerHediff>Some_HediffDef</triggerHediff>
```

处理方式：

- 所有 XML 和文档中的 `<tiggerHediff>`、`<TiggerHediff>` 已迁移为 `<triggerHediff>`。
- `TickDamage`、`SelfHediffSetting`、`DamageSetting` 和范围技能 VerbProperties 中删除旧拼写字段。
- 圆形脱手技能、扇形持续技能、矩形持续技能、延迟自我 Hediff、持续伤害片段统一只读取 `triggerHediff`。

## 配置要求

从本次迁移后，新配置不要再写 `tiggerHediff` 或 `TiggerHediff`。

圆形脱手技能的单段配置应写：

```xml
<triggerHediff>BAWN_Kei_buff</triggerHediff>
```

如果目标 Hediff 是叠层 Buff，`HediffDef` 需要包含：

```xml
<li Class="BANWlLib.BattleSystem.HediffCompProperties_BattleStack">
```

运行时会通过 `BattleStackHediffUtility.ApplyStackedHediff` 处理重复施加，已有状态会加层并按配置刷新持续时间。

## 注意事项

当前项目的 `1.6/Defs` 中没有搜索到 `BAWN_Kei_buff` 的 `HediffDef`。如果配置中引用这个 Def，需要确认该 Def 已经添加到会被 RimWorld 加载的 XML 中，并且带有叠层组件配置。

## 加载日志修复

本次也清理了 `Player.log` 中属于本项目的加载期错误：

- `PawnKinds_Mika_A.xml` 中泳装未花的 `PawnKindDef` 改为 `BANW_Mika_A`，不再和普通未花的 `BANW_Mika` 重名。
- `PawnKinds_Mika_A.xml` 删除重复声明的 `BAWC_TraitDef_Mika_A`、`BAWC_TraitDef_Mika_B`、`BAWC_TraitDef_Mika`，泳装未花继续引用普通未花文件中已经存在的 TraitDef。
- 新增 `BANW_Mika_A_Proplevel`，用于 `BANW_Mika_A_Student` 的学生碎片配置。
- 新增 `BANW_Body_Mika_A`，用于 AlienRace 服装列表和泳装未花 PawnKind。
- `FontDef.xml` 删除不存在的 `BANC_Damage_Mika_A` 暴击规则项。当前项目只有 `BANC_Damage_Mika` 和 `BANC_Damage_Mika_None`。
- `MissionNode.xml` 删除空的任务目标 `<li></li>`。

这些修复后，需要重新启动 RimWorld 才会生成新的 `Player.log`。旧日志中已经写入的错误不会自动消失。
