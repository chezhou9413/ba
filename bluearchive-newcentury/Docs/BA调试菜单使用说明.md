# BA 调试菜单使用说明

启用开发者模式，进入存档后打开顶部的调试操作菜单，点击 **BA调试...**，再选择需要的子页面。首页只显示一个 BA 调试入口。

| 子页面 | 可用功能 |
| --- | --- |
| 抽卡与招募 | 切换抽卡必出三星、增加 100 点招募点数、强制刷新卡池 |
| 学生档案 | 查看已获得学生、收藏名单、所选学生的存档数据 |
| 任务进度 | 查看任务节点和完成记录、完成指定或全部任务、清空或删除完成记录 |
| 战斗测试 | 生成战斗测试场景、施加攻击层数或测试伤口、查看战斗属性、切换公式日志 |
| 特殊技能 | 生成七名角色或指定角色、补满共享 COST、重置或查看新技能状态、手动触发普通技能 |
| UI内存 | 输出图片内存统计、释放闲置图片 |

点击页面上方的原版菜单路径可返回上一层，选择另一组操作。

需要地图的页面只在当前地图可用时显示。在世界界面仍可使用抽卡与招募页面。需要“选中角色”的操作应先在地图中选中对应角色，再打开调试菜单。

名称带 `T:` 的操作会进入地图点选模式，点击地图后执行；按 Esc 退出工具。例如“生成全部七名正式角色”需要点击生成位置。“选择生成一名正式角色”还会先进入角色选择页面。

查看列表、属性和图片内存的操作会向游戏日志输出信息；部分学生资料和技能状态也会显示消息窗口。

特殊技能的参数与测试方法见[特殊技能 XML 配置说明](特殊技能XML配置说明.md)，图片缓存配置见[UI 图片打包与内存配置](UI图片打包与内存配置.md)。
