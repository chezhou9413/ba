# 凯伊场地与自动普通技能

配置文件：[Kei.xml](../1.7/Defs/SpecialSkills/Kei.xml)。

## EX场地来源

`kei.sourceExAbility` 指向现有技能 `BAWN_Kei_EXX`（存在于此的我）。现有EX完成施法、实际场地生成后，开始蓄积。测试EX共用来源技能的场地定义、增益动作和持续时间设置，范围预览也读取该场地半径。

场地配置位于 `1.7/Defs/AbilityDef/Kei.xml`：

| 参数 | 作用 |
| --- | --- |
| EX组件 `fieldThingDef` | 实际场地实体，目前为 `BANW_BattleField_Kei_Test` |
| EX组件 `durationTicksOverride` | 覆盖场地时长，默认1500 tick，即25秒；不大于0时读取场地的 `durationTicks` |
| 场地 `radius` | 实际圆形格子范围，默认4.9格 |
| 场地 `intervalTicks` | 给范围内友军刷新状态的间隔，默认100 tick |
| 场地 `actions` | 实际增益动作，目前施加 `BAWN_Kei_buff` |

蓄积要求友军已获得 `kei.contributionHediff`，并仍处于此场地的实际格子范围内。若更换场地增益状态，也要对应修改这个参数；省略它则只检查实际范围。自身伤害、对非敌对目标的伤害、场地外友军伤害不计入。

`recordRatio=0.1` 表示计入友军有效伤害的10%；`recordCapRatio=50` 表示上限为施法时攻击基数的50倍。攻击基数由 `burstAttack.useBattleStats` 决定：开启时读取BA攻击力，关闭时读取 `burstAttack.basePower`。

## 普通技能施法

场地到期后，凯伊在征召且可行动时自动寻找25格内的可见敌人，优先使用当前攻击目标。普通技能不消耗COST，没有独立主动按钮，也不按固定周期触发。

流程为：停步瞄准 → 前摇期间播放语音和特效 → 同次施法发射两段单体实体弹丸 → 各自命中时独立结算伤害。

两段分别为：

- `normalAttack`：造成自身攻击力281%的伤害，`attackPowerRatio=2.81`，按普通技能的BA属性、暴击和克制结算，不视为武器普攻。
- `burstAttack`：造成增幅装置伤害记录量100%的伤害，`attackPowerRatio=1`。金额为已记录伤害乘该倍率，不再次叠加攻击力、暴击、克制或输出倍率，也不再次参与伤害蓄积。

| 参数 | 作用 |
| --- | --- |
| `range` | 普通技能选敌射程，默认25格 |
| `kei.warmupTicks` | 前摇时长，默认60 tick，即1秒，必须大于0 |
| `kei.warmupSound` | 前摇语音，默认 `Kei_Skill_EXX` |
| `kei.warmupEffecter` | 前摇期间维护的特效，默认 `BANW_Kei_Ef_B` |
| `kei.castSound` | 发射声音，默认 `BANW_Wp_HG_At` |
| `kei.casterEffecter` | 发射时施法者特效，支持项目现有定向特效子节点 |
| `kei.targetEffecter` | 发射时目标特效 |
| `normalAttack.attackPowerRatio` | 攻击力伤害段的倍率，默认2.81，即281% |
| `burstAttack.attackPowerRatio` | 记录伤害段的释放比例，默认1，即100% |
| 两段各自的 `projectileDef` | 实体弹丸，默认 `BANW_SpecialSkillBullet`，须使用 `Projectile_SpecialSkill` 类 |
| 两段各自的 `effecterDef` | 弹丸命中特效，可分别设置 |
| 两段各自的 `damageDef` | 独立伤害类型 |
| 两段各自的 `penetration` | 护甲穿透，0.5代表50% |
| 两段各自的 `shots` / `radius` | 必须分别为1和0，确保每段单发单体 |

两段分别处理命中后的护甲、闪避和护盾。没有蓄积时，记录伤害段为0，攻击力伤害段仍正常造成281%攻击力的伤害。比如攻击力100、记录量500，在没有其他倍率与减伤时，两段分别为281和500，不合并为一次伤害请求。状态说明分别显示攻击力伤害公式与当前可释放的记录伤害。

无敌人、无法行动或前摇中断时保留蓄积与释放机会；目标失效、移出射程或失去视线会中断前摇。发射后消耗此次机会。技能不会打断正在执行的其他能力施法，前摇期间停止武器连射。

现有EX多次施法分别保留各自场地的记录与释放机会。离图不会销毁EX场地或提前触发普通技能；到期后保留资格，回到地图且满足行动条件时再释放。测试EX仍限制同一状态在场地有效或待释放期间再次施放。
