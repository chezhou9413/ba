# 通用普通技能与目标伤害特效配置说明

这份文档说明角色如何绑定通用普通技能、设置目标类型和队友筛选、配置伤害或Buff，以及调整妮露二段EX的命中特效方向。通用普通技能按主武器普攻事件自动触发，不提供主动按钮，也不消耗COST。

爱丽丝和星野继续使用原来的专属执行器：爱丽丝按有效普攻命中计数，星野按成功射出的普攻发数计数。它们的充能、形态、强化攻击和原有倍率保持原来的行为。只有明确添加到角色`normalSkills`列表的通用技能才会生效。

## 角色绑定入口

在角色的`PawnKindDef/modExtensions`中使用`BANWlLib.Skills.SpecialSkillKindExtension`：

```xml
<modExtensions>
  <li Class="BANWlLib.Skills.SpecialSkillKindExtension">
    <normalSkills>
      <li>BANW_Normal_AttackExample</li>
      <li>BANW_Normal_AllyBuffExample</li>
    </normalSkills>
  </li>
</modExtensions>
```

同一个角色可以挂多个技能，每个技能独立计数、独立冷却。仅使用通用普通技能的角色不需要填写`profile`，也不需要额外配置EX按钮或COST组件。

如果角色已经持有这个扩展，请在现有`li`中追加`normalSkills`，保留原来的`profile`。不要再创建第二个同类扩展；角色读取的是一个扩展中的配置。已有其他`modExtensions`时同样保留它们。

示例定义没有默认绑定任何角色。绑定后角色生成或进入地图时安装对应状态；修改Def后需重新加载游戏配置。这里只保存当前定义的运行状态，没有编写旧存档迁移流程。

## 触发次数入口

这些字段放在`BANWlLib.Skills.NormalSkillDef`下：

```xml
<countMode>ShotFired</countMode>
<requiredCount>3</requiredCount>
<cooldownTicks>60</cooldownTicks>
<range>25</range>
```

| 字段 | 含义 |
|---|---|
| `countMode=ShotFired` | 主武器每成功射出一发计一次，射偏或目标闪避仍计数；不是一整轮连射计一次 |
| `countMode=EffectiveHit` | 普攻实际造成非零伤害计一次；完全闪避、护盾完全吸收不计数 |
| `requiredCount` | 发动一次技能所需次数，必须大于零 |
| `cooldownTicks` | 成功发动后的冷却，最小为1；60tick为1游戏秒 |
| `range` | 自动寻找目标的范围，单位为格 |

只有征召、存活、未倒地、未眩晕且具有操作能力时才能自动发动。就绪但没有合法目标时保留进度；成功发动后只扣除`requiredCount`，多余次数继续保留。冷却期间仍可累计进度。

通用普通技能不会中断主武器连射，也不创建停步前摇工作。它安排独立效果或技能弹丸；专属角色原有的前摇和连射等待规则继续由专属模块执行。

通用动作不能标记为`isNormalAttack=true`或`isExSkill=true`。通用技能伤害和无人机技能伤害不进入通用普攻累计，避免追加攻击循环触发。发射计数接收主武器投射物动词事件；近战攻击没有接入这个入口。有效命中按一次实际伤害事件计数，范围普攻可对不同受击目标分别计数。

## 目标类型和队友入口

通用普通技能把以下节点直接写在`NormalSkillDef`下：

```xml
<onlyTargetAllies>true</onlyTargetAllies>
<targetParams>
  <canTargetLocations>false</canTargetLocations>
  <canTargetSelf>false</canTargetSelf>
  <canTargetPawns>true</canTargetPawns>
  <canTargetBuildings>false</canTargetBuildings>
  <canTargetAnimals>true</canTargetAnimals>
  <canTargetHumans>true</canTargetHumans>
  <canTargetMechs>true</canTargetMechs>
</targetParams>
```

`onlyTargetAllies=true`只选择同阵营且不敌对的Pawn；盟友派系、中立访客和囚犯不会仅因“不敌对”就被当成队友。它先筛选类型、距离、视线和存活状态，再按当前生命百分比由低到高选择。同百分比优先距离最近者，再按实体编号稳定选择。生命比例使用项目当前的`SummaryHealthPercent`，不按剩余生命绝对值比较。

`canTargetSelf=false`排除施法者，改为`true`则自身也参与队友排序。纯Buff技能可以选满血队友，没有额外的“必须受伤”条件。倒地队友默认可选；要排除倒地者，可以在`targetParams`中设置`neverTargetIncapacitated=true`。

`onlyTargetAllies=false`自动选择敌人，优先合法的当前攻击对象，否则选择范围内最近敌人。自动技能没有自动选择空地的规则，所以`canTargetLocations`必须保持`false`。自动建筑攻击需同时设置`canTargetBuildings=true`和动作的`canHitBuilding=true`；建筑单体伤害使用`radius=0`，现有范围伤害仍枚举Pawn。

目标筛选和动作作用开关是两层条件。队友支援动作还要配置：

```xml
<affectFriendly>true</affectFriendly>
<affectHostile>false</affectHostile>
```

普通支援动作不需要开启`canHitOwnPawn`；这个字段涉及伤害误伤。如果刻意对同阵营队友造成伤害，需要明确设置`canHitOwnPawn=true`。

单体和范围效果在实际命中时继续检查类型、阵营和自身开关。已发出的弹丸不会因为施法者移动或失去原先视线而重新检查施法距离。

## 主动特殊技能的目标入口

主动技能仍在`AbilityDef/verbProperties/targetParams`中设置原版目标类型。最终施法校验也读取这些参数，不能只通过组件直接绕过类型筛选。

仅限队友开关放在特殊技能组件中：

```xml
<li Class="BANWlLib.Skills.CompProperties_SpecialSkill">
  <profile>BANW_Special_Nero</profile>
  <command>Ex</command>
  <onlyTargetAllies>true</onlyTargetAllies>
</li>
```

这里限制手动选择范围，不会自动替玩家选择最低生命队友。自动最低生命选择属于`NormalSkillDef`。妮露一段已开启这个开关。

角色专属机制仍参与校验。例如爱丽丝对自身充能、妮露二段攻击敌人、莉音复制队友技能、星野防御EX选择落点，不能仅靠类型开关把这些行为转换成另一种技能。主动技能的`verbProperties.range`和专属配置`profile.range`也需要保持一致。

## 伤害动作入口

通用技能的真实动作放在`NormalSkillDef/actions/li`，不是放在`previewActions`中：

```xml
<actions>
  <li>
    <useBattleStats>true</useBattleStats>
    <attackPowerRatio>4.68</attackPowerRatio>
    <damageDef>BANC_Damage_baofa</damageDef>
    <canCrit>true</canCrit>
    <alwaysCrit>false</alwaysCrit>
    <applyAffinity>true</applyAffinity>
    <isExSkill>false</isExSkill>
    <isNormalAttack>false</isNormalAttack>
    <penetration>0</penetration>
    <shots>1</shots>
    <radius>0</radius>
    <projectileDef>BANW_SpecialSkillBullet</projectileDef>
    <effecterDef>BANW_Effecter_C</effecterDef>
    <affectHostile>true</affectHostile>
    <affectFriendly>false</affectFriendly>
  </li>
</actions>
```

`attackPowerRatio=4.68`表示本动作总计468%攻击力伤害。如果`shots=3`，每发承担156%。它不是三发各468%。每个`li`独立配置总倍率、伤害类型、暴击、克制和穿透；整套技能可以使用多个动作。

BA伤害按“角色攻击基数×攻击力加成×技能倍率×暴击×克制×机制倍率”计算。标记为EX的专属攻击段另外参与EX倍率。实际扣血仍处理目标护甲、闪避、承伤和护盾，按钮基础预估不会预知最终选中的敌人属性。

`useBattleStats=false`时使用`basePower×attackPowerRatio`作为本段总基础伤害，不读取BA输出乘区。`basePower`是独立攻击基数，不是额外加上的固定伤害；在BA模式下它也不是“固定伤害加攻击力倍率”的加法项。

删除`projectileDef`则使用直接效果；填写时必须使用`Projectile_SpecialSkill`类型。`radius=0`为单体，正数为落点周围Pawn范围效果；范围半径与自动选目标的`range`含义不同。

`shotIntervalTicks`控制统一发射间隔，首发在第1tick。可用`shotTicks`逐项指定相对生效时刻，每项至少为1、按时间排列，条目数量必须等于`shots`。`shotSound`每次实际发射时播放。

## 队友Buff和治疗入口

可直接绑定示例`BANW_Normal_AllyBuffExample`，它每3发普攻给最低生命比例队友提供5秒攻击支援。Buff动作的核心字段是：

```xml
<li>
  <triggerHediff>BANW_Normal_AllyAttackBuff</triggerHediff>
  <buffDurationTicks>300</buffDurationTicks>
  <shots>1</shots>
  <radius>0</radius>
  <affectFriendly>true</affectFriendly>
  <affectHostile>false</affectHostile>
</li>
```

纯Buff不填`damageDef`，也不需要`attackPowerRatio`或弹丸。`triggerHediff`是实际效果入口；Buff属性加成写在该HediffDef的`stages/statOffsets`中。

使用`BANWlLib.Skills.TimedSkillBuff`及其派生类时，动作的`buffDurationTicks`必须大于零，再次获得同类Buff会刷新持续时间。普通Hediff仍使用自身组件管理持续时间，`buffDurationTicks`不会替它改变生命周期。

治疗动作使用`isHealing=true`和`healPowerRatio`；护盾动作使用`isShield=true`、`shieldPowerRatio`和`shieldHediffDef`。伤害、治疗和护盾拆成不同动作；`triggerHediff`可以附加在其中任一动作后。治疗总倍率按发数均分；护盾每发授予完整配置值，按照已有护盾覆盖规则刷新，不把多发护盾相加。

`shieldSource`可选择`HealPower`、`MaxHealth`或`Independent`。对应使用施法者治愈力、施法者最大生命或`basePower`；关闭BA时使用独立基数。支援类数值也通过公共战斗请求执行，纯Buff不会伪装成一次零伤害攻击。

## 伤害公式显示入口

通用普通技能在自身运行状态的悬浮说明中显示真实动作公式，用`NormalSkillDef/showBattleFormula`控制。纯Buff显示附加状态名称，不生成零伤害公式。

主动特殊技能按钮直接读取实际角色配置：妮露二段包含下一次施放将获得的锐气层数，爱丽丝包含当前充能档位，星野攻击EX读取独立分段，防御EX显示最大生命护盾公式。若藻EX显示子弹伤害；蓄积爆发由目标标记中锁定的换算结果决定，不能用按钮基础伤害替代。凯伊读取真实场地的战斗动作。

爱丽丝、星野和黑子的专属自动普通技能公式位于特殊技能状态说明中。`SpecialSkillProfileDef/showNormalBattleFormula=false`可关闭这部分公式；凯伊状态直接显示已经确定的待释放金额。

主动特殊技能可以在`AbilityDef/modExtensions`中关闭公式：

```xml
<li Class="BANWlLib.BattleSystem.AbilityBattleTooltipExtension">
  <showBattleFormula>false</showBattleFormula>
</li>
```

保持开启时无需再手写特殊技能的`previewActions`。公共悬浮工具仍支持手动`previewActions`，用于没有自动解析入口的技能；它只负责说明，不产生伤害。实际特殊技能配置优先于手填预览，避免改了伤害却忘记同步另一份倍率。

## 妮露命中特效方向入口

施法者位置的旋转特效使用`SpecialSkillProfileDef/casterEffecter`，妮露一段的阶段特效使用`stageEffecter`。原水花子子节点在触发时确定方向；妮露二段的`BANW_Nero_B_Ef_D`使用引导专用子节点，按当前目标位置实时旋转偏移和贴图，生成的Mote保持到引导Job结束，中断时清理。实时转向需要`absoluteAngle=false`。`stageEffecter`只在一段朝向所选队友播放，`casterEffecter`一段也会按普通Mote时长播放。详细配置见[妮露EX技能配置说明](妮露EX技能配置说明.md)。

在`1.6/Defs/AbilityDef/Nero_B.xml`的`SpecialSkillProfileDef/exAttack`中设置：

```xml
<effecterDef>BANW_Effecter_C</effecterDef>
<rotateImpactEffect>true</rotateImpactEffect>
<impactRotationOffset>0</impactRotationOffset>
```

`rotateImpactEffect=true`让命中特效叠加该颗弹丸实际飞行方向；改为`false`沿用普通落点特效。`impactRotationOffset`是贴图轴向校正角，例如素材需要向左校正90度时填写`-90`。最终贴图角度为“弹道角度＋子特效rotation＋impactRotationOffset”。运动方向沿原先的发射角度配置叠加弹道方向，贴图校正不额外改变运动方向。

这套开关也能放在其他`SpecialAttackConfig`动作下。直接伤害使用发射时施法者到落点的方向，弹丸伤害使用实际命中弹道方向。每次命中只走一个命中特效入口，不重复播放普通和定向表现。

原版`SubEffecter_Sprayer`派生子节点支持Mote和Fleck，数量、颜色、缩放、速度、延迟和旋转速度继续取原配置。定向开关接管子节点的绝对角度和目标朝向选项；共享EffecterDef不被修改。延迟播放固定本次命中格和角度，不跟随之后的转身或移动。

已有`BANWlLib.Projectiles.SubEffecter_DirectionalImpactMote`也可以复用。使用这种子节点时，额外运动参数位于攻击段：`impactEffectSpeed`控制飞出速度，`impactOffsetForward`控制沿弹道偏移，`impactOffsetUp`控制生成高度，默认均为0。它沿用项目已有的定向Mote延迟队列。普通喷射子节点的速度继续在EffecterDef中设置。

## 编译与配置错误

源码属于现有`Skills/**/*.cs`编译入口，不需要为每个通用技能创建C#类。构建命令为：

```powershell
MSBuild.exe 'E:\RimModDev\bluearchive-newcentury\bluearchive-newcentury\Source\BANWlLib\BANWlLib.csproj' /t:Build /p:Configuration=Release /p:Platform=AnyCPU /nologo /verbosity:minimal
```

DLL输出到项目`1.6/Assemblies/BANWlLib.dll`。配置错误会直接报告日志：次数或时间无效、逐发表数量错误、错误弹丸类型、普通技能误标EX或普攻、缺少实际动作、队友动作关闭友军作用等都不会通过静默回退替换配置。

本次验证仅运行工程Release编译，不启动游戏或执行运行时场景测试。
