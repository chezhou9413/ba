# 爱丽丝测试技能配置说明

对应“光之勇者”和由普攻命中自动触发的“勇气的魔法”。1.6与1.7使用相同的本套技能参数；1.7同时包含对应的爱丽丝特效与声音定义。现有角色旧技能不在这套配置中。

## 文件分工

| 文件 | 内容 |
|---|---|
| `1.6/Defs/SpecialSkills/Arisu.xml` | EX按钮、直线尺寸、多段伤害、充能与对敌特效引用 |
| `1.6/Defs/Effecter/Arisu_B.xml` | 爱丽丝的三档光束、两档充能与普通技能前摇特效 |
| `1.6/Defs/SpecialSkills/ArisuNormal.xml` | 独立自动普通技能，包含触发、冷却、音效、特效、伤害与护甲穿透 |

## 三档对敌特效与两档充能

`Arisu.xml` 的 `arisu.attackEffecters` 必须配置三项：

| 使用前充能 | 播放的特效 |
|---|---|
| 0档 | 第1项，`BANW_Arisu_B_Ef_C` |
| 1档 | 第2项，`BANW_Arisu_B_Ef_D` |
| 2档 | 第3项，`BANW_Arisu_B_Ef_E` |

对敌时只播放对应档位的一套特效，并清空充能。声音使用 `arisu.attackSound`。

`arisu.chargeEffecters` 必须配置两项，分别对应自身从0升至1档、从1升至2档，当前为 `BANW_Arisu_B_Ef_A`、`BANW_Arisu_B_Ef_B`。`arisu.chargeWarmupTicks` 控制自身充能前摇，当前60 tick（1秒）；特效与可选的 `arisu.chargeSound` 在前摇开始时播放，前摇完成才加档并扣除COST，中断前摇不获得充能。两个Effecter已有各自声音子项时，不必重复填写chargeSound。

如果还需要在持有充能期间持续显示特效，可选填 `arisu.chargeStateEffecters`，同样严格按第一档、第二档配置两项。未填写时只播放充能瞬间的特效，避免重复播放。持续特效在升档或对敌释放后清理。

## 定向特效配置

对敌特效沿用水花子的 `BANWlLib.BaClass.SubEffecter_SprayerTriggeredRotatedOffset`。代码按本次瞄准方向同时旋转 `positionOffset` 与特效自身角度；`initialDelayTicks` 大于0时保存施法瞬间的位置和方向，目标移动后不会使后续节点偏转。

```xml
<li>
  <subEffecterClass>BANWlLib.BaClass.SubEffecter_SprayerTriggeredRotatedOffset</subEffecterClass>
  <moteDef>BAWN_Hanako_A_3_Mote</moteDef>
  <initialDelayTicks>0</initialDelayTicks>
  <scale>0.625</scale>
  <rotation>0</rotation>
  <positionOffset>(0,0.5,12.5)</positionOffset>
  <absoluteAngle>false</absoluteAngle>
</li>
```

- `moteDef`：实际表现资源，可分别更换A／B／C的节点。
- `positionOffset`：本地横向、绘制高度、前向偏移。默认前移12.5格，使素材中心落在线段中间。
- `rotation`：素材朝向校正角；`absoluteAngle=false` 时叠加瞄准方向。
- `initialDelayTicks`：仅控制该特效节点的延迟，不改变伤害时间。
- `scale`：表现缩放；占位素材宽度不代表真实命中范围，以直线预览为准。

当前使用爱丽丝自己的EffecterDef。上面的定向子节点示例仍可用于替换素材；普通技能也可使用同类定向子节点。延迟及持续子特效由地图维护，不在触发后立刻清理。

## 直线多段伤害

| 字段 | 默认值与作用 |
|---|---|
| `arisu.lineLength` | 40.9，直线长度 |
| `arisu.lineWidth` | 3，直线全宽 |
| `arisu.damageDelayTicks` | 160，额外首段延迟，约2.67秒 |
| `arisu.chargeWarmupTicks` | 60，自身充能前摇，0表示不等待 |
| `exAttack.shots` | 22，伤害段数 |
| `exAttack.shotIntervalTicks` | 6，段间隔0.1秒 |
| `exAttack.attackPowerRatio` | 53.2，未充能总倍率5320%，按段数均分 |
| `exAttack.penetration` | 2，每段独立应用完整穿透；0.5为50% |

当前0／1／2档总倍率分别为5320%／10640%／15960%，分别均分为22段。`useBattleStats=false` 时按 `basePower` 计算，充能倍数仍保留。这里按配置总倍率解释，不再把53.2写成1330%。

范围预览和实际伤害共用直线格子算法。施法时固定起点和方向，后续每段对当前处于这条线中的敌人各结算一次伤害，不生成单体追踪弹丸，也不在目标周围结算圆形爆炸。原目标死亡不取消后续段；离开直线范围的角色不再受到后续段伤害，进入范围的角色可被命中。

攻击EX使用 `BANW_Job_ArisuExChannel` 保持停步瞄准，最后一段伤害完成后自然结束。伤害延迟和逐段时间决定动作时长；设置 `exAttack.shotTicks` 时以最后一段时间为准。成功发动的光束独立保存伤害队列，右键移动等结束瞄准动作不会取消余下伤害；施法者死亡或离开当前地图时不再结算。已消费的充能与COST不退回，自身充能则先完成独立前摇。

沿用项目直线范围算法，命中区域不因墙体而截断，目标选取仍要求合法射程与视线。EX的选取与伤害使用`exAttack`的阵营开关：`affectHostile`允许敌对及无阵营生物，`affectFriendly`允许其他非敌对阵营，`canHitOwnPawn`允许己方生物；当前只有`affectHostile`开启。`AbilityDef/verbProperties/targetParams`继续控制人类、动物、机械体等目标类型。点自己始终用于充能，自动普通技能仍按原规则寻找敌人。EX释放期间暂缓独立普通技能触发，避免同时播放两套技能表现。

保持 `exAttack.radius=0`，不要填写 `projectileDef`。改变技能选取距离时调整角色 `range` 与 AbilityDef 的 `verbProperties.range`；线的实际长度由 `lineLength` 独立控制。

## 独立自动普通技能

`ArisuNormal.xml` 使用独立的 `BANWlLib.Skills.ArisuNormalSkillDef`，由EX配置中的 `arisu.normalSkill` 引用。它不注册AbilityDef、不产生主动按钮，仅由命中事件自动触发。

| 字段 | 作用 |
|---|---|
| `requiredHits` | 有效普攻命中阈值，当前20；完全闪避或完全吸收不计数 |
| `cooldownTicks` | 两次普通技能间的最小间隔，默认1；独立于EX冷却 |
| `range` | 普通技能独立索敌距离，当前39.9 |
| `warmupTicks` | 独立前摇，当前60 tick，0表示不等待 |
| `jobDef` | `BANW_Job_ArisuNormalSkill`，承载前摇和持续瞄准 |
| `castSound` | 前摇开始时播放的声音 |
| `casterEffecter` | 前摇开始时播放的自身特效，至少维护到前摇结束 |
| `targetEffecter` | 技能发动时的目标位置特效 |
| `attack.effecterDef` | 弹丸实际命中时的特效 |
| `attack` | 独立伤害、弹丸、连射、范围、暴击与穿透配置 |

当前单体12发、总倍率1828%、穿透2。`attack.isExSkill=true` 允许使用EX独立伤害乘区，但普通技能仍不消费COST或充能，也不乘以充能档位。技能自身的伤害不计入触发次数。真正发射时才消费20次命中；前摇中断保留进度，移动中不会反复抢占移动指令。没有有效目标或EX尚未结束时等待机会。

技能状态名称直接读取 `SpecialSkillProfileDef.label`。按钮只显示简短状态与当前EX总预估，普通技能完整公式保留在健康面板的状态说明中。

不需要某个可选音效或特效时删除对应字段。所有配置值和引用随正常Def加载；显式填写的资源必须存在，配置错误直接输出游戏日志。
