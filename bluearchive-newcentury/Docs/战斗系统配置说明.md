# 战斗系统配置说明

本文档说明BA战斗系统里技能伤害、治疗、暴击、属性克制、直线弹、脱手场地和叠层状态的 Def 配置方式。

## 核心概念

当前战斗系统把数值拆成三层：

1. 技能段配置：写这一段技能什么时候触发、基础值是多少、吃多少攻击力或治疗力。
2. 角色属性配置：写角色自身攻击力、治疗力、暴击、受疗率、克制加成。
3. 属性克制配置：写攻击类型打护甲类型时的倍率矩阵。

技能段负责描述“这一段怎么打”，角色属性负责描述“施法者有多强”，克制矩阵负责描述“打这个目标是否优势”。

## 当前真实伤害公式

当前代码位置：

```text
Source/BANWlLib/BattleSystem/BattleStatUtility.cs
```

真实伤害公式是：

```text
攻击平加 = BANW_RangedWeapon_Damage
        + 学生基础属性 attackFlat
        + 叠层状态对 BANW_RangedWeapon_Damage 的加值
        + 阶级成长 attackFlat

攻击倍率 = 1
        + 学生基础属性 attackPercent
        + BANW_FinalDamageMultiplier
        + 叠层状态对 BANW_FinalDamageMultiplier 的加值
        + 阶级成长 attackPercent

最终攻击力 = 攻击平加 * 攻击倍率

基础部分 = (baseAmount + 攻击平加) * 攻击倍率

倍率部分 = 最终攻击力 * attackPowerRatio

暴击前伤害 = 基础部分 + 倍率部分

最终伤害 = 暴击前伤害 * 暴击倍率 * 属性克制倍率
```

等价写法：

```text
最终伤害 =
(
  (baseAmount + 攻击平加) * 攻击倍率
  + (攻击平加 * 攻击倍率) * attackPowerRatio
)
* 暴击倍率
* 属性克制倍率
```

重要注意：

```xml
<baseAmount>0</baseAmount>
<attackPowerRatio>1.18</attackPowerRatio>
```

按当前代码不是单纯 118% 攻击力。

因为 `baseAmount=0` 仍会进入：

```text
(0 + 攻击平加) * 攻击倍率
```

所以它实际等于：

```text
100% 攻击力 + 118% 攻击力 = 218% 攻击力
```

如果后续想让配置语义变成“真正的固定值 + 攻击力倍率”，代码应改成：

```text
最终伤害 = baseAmount + 最终攻击力 * attackPowerRatio
```

## 技能单段伤害配置

持续范围技能使用：

```text
Source/BANWlLib/Pojo/TickDamage.cs
```

典型配置位置：

```text
1.6/Defs/AbilityDef/Hanako_A.xml
```

配置结构：

```xml
<JobDef Class="BANWlLib.BaDef.BaJobDef_SustainedAttack">
  <defName>BANW_Job_Skill_Hanako_A_EXX</defName>
  <driverClass>BANWlLib.BaJob.Job_SustainedAreaAttack</driverClass>
  <damages>
    <li>
      <!-- 这一段在 Job 开始后的第几个 tick 触发。 -->
      <tick>70</tick>

      <!-- 旧固定伤害字段，迁移期兼容用；新技能建议写 baseAmount。 -->
      <damageAmount>0</damageAmount>

      <!-- 固定基础值。当前代码里会和攻击平加一起吃攻击倍率。 -->
      <baseAmount>0</baseAmount>

      <!-- 攻击力倍率，1.18 表示 118%。当前代码还会额外带一份基础攻击力。 -->
      <attackPowerRatio>1.18</attackPowerRatio>

      <!-- 治疗力倍率。伤害段不填或填 0。 -->
      <healPowerRatio>0</healPowerRatio>

      <!-- false 表示伤害，true 表示治疗。 -->
      <isHealing>false</isHealing>

      <!-- RimWorld DamageDef，决定原版伤害类型、伤口类型和部分命中特效。 -->
      <damageType>BANC_Damage_Hanako_A_EXX</damageType>

      <!-- 护甲穿透。 -->
      <penetration>0.35</penetration>

      <!-- 是否可以暴击。 -->
      <canCrit>true</canCrit>

      <!-- 是否应用攻击类型和护甲类型克制。 -->
      <applyAffinity>true</applyAffinity>

      <!-- 是否影响敌对目标。 -->
      <affectHostile>true</affectHostile>

      <!-- 是否影响友方目标。伤害技能通常为 false，治疗技能通常为 true。 -->
      <affectFriendly>false</affectFriendly>

      <!-- 是否允许命中建筑。 -->
      <isAttackBuilding>false</isAttackBuilding>

      <!-- 这一段触发时在范围中心播放的特效。 -->
      <effecterDef>BANW_Hanako_Ef_B</effecterDef>
    </li>
  </damages>
</JobDef>
```

每一个 `<li>` 就是一段伤害。多段技能要给每一段都写一次 `tick` 和 `attackPowerRatio`。

例如总倍率 708%，分 6 段：

```text
每段设计倍率 = 708% / 6 = 118%
attackPowerRatio = 1.18
```

但按当前真实代码，它会变成每段约 218% 攻击力。如果要严格还原总倍率，需要先修公式，或临时把 `attackPowerRatio` 按当前多出来的 100% 抵消。

## 延迟圆形范围技能配置

延迟范围技能使用：

```text
Source/BANWlLib/Pojo/TickDelayDamageAndHediff.cs
```

主段类型是 `TickDelayDamageAndHediff`，子段类型是 `DamageSetting`。

配置结构：

```xml
<damages>
  <li>
    <!-- 主时间轴 tick。 -->
    <tick>30</tick>

    <!-- 主段范围中心特效。 -->
    <effecterDef>BANW_Effecter_A</effecterDef>

    <damages>
      <li>
        <!-- 主段触发后延迟多少 tick 结算这个子段。 -->
        <Delaytick>0</Delaytick>

        <!-- 固定基础值。 -->
        <baseAmount>0</baseAmount>

        <!-- 攻击力倍率。 -->
        <attackPowerRatio>1.5</attackPowerRatio>

        <!-- 伤害 Def。 -->
        <damageType>BANC_Damage_Test</damageType>

        <!-- 可选 Hediff。 -->
        <tiggerHediff>Some_HediffDef</tiggerHediff>

        <!-- 子段范围中心特效。 -->
        <effecterDef>BANW_Effecter_B</effecterDef>

        <canCrit>true</canCrit>
        <applyAffinity>true</applyAffinity>
        <affectHostile>true</affectHostile>
        <affectFriendly>false</affectFriendly>
      </li>
    </damages>
  </li>
</damages>
```

`effecterDef` 的触发位置：

- 主段 `effecterDef`：主段触发时在技能目标点播放。
- 子段 `DamageSetting.effecterDef`：子段结算时在技能目标点播放。
- 不再依赖命中目标才播放。

## 角色攻击属性配置

攻击平加来自：

```text
BANW_RangedWeapon_Damage
叠层状态对 BANW_RangedWeapon_Damage 的加值
阶级成长 attackFlat
```

攻击倍率来自：

```text
1 + BANW_FinalDamageMultiplier
叠层状态对 BANW_FinalDamageMultiplier 的加值
阶级成长 attackPercent
```

可以在 Pawn、装备、Hediff、Trait 等支持 StatDef 的地方配置。

例如装备、Hediff、Trait 的基础 Stat：

```xml
<statBases>
  <!-- 攻击平加。 -->
  <BANW_RangedWeapon_Damage>100</BANW_RangedWeapon_Damage>

  <!-- 攻击倍率加成，0.2 表示 +20%。 -->
  <BANW_FinalDamageMultiplier>0.2</BANW_FinalDamageMultiplier>
</statBases>
```

注意：`PawnKindDef` 本身没有 `statBases` 字段。学生固有基础属性不要写在 `PawnKindDef.statBases`，要写在下面的 `BattleBaseStatExtension`。

## 学生基础属性配置

学生固有基础属性挂在 `PawnKindDef.modExtensions`。

配置类：

```text
BANWlLib.BattleSystem.BattleBaseStatExtension
```

示例：

```xml
<modExtensions>
  <li Class="BANWlLib.BattleSystem.BattleBaseStatExtension">
    <!-- 学生基础生命尺度平加，参与 Pawn.HealthScale 计算，不是直接最终生命值。 -->
    <healthFlat>0</healthFlat>

    <!-- 学生基础生命尺度百分比，0.2 表示生命尺度额外增加 20%。 -->
    <healthPercent>0</healthPercent>

    <!-- 学生基础攻击力平加，进入技能、武器显示和统一伤害结算。 -->
    <attackFlat>100</attackFlat>

    <!-- 学生基础攻击力百分比，0.26 表示最终攻击力额外增加 26%。 -->
    <attackPercent>0.26</attackPercent>

    <!-- 学生基础治疗力平加，会叠加到 BANW_HealPowerBase 后参与治疗公式。 -->
    <healFlat>0</healFlat>

    <!-- 学生基础治疗力百分比，0.2 表示最终治疗力额外增加 20%。 -->
    <healPercent>0</healPercent>

    <!-- 学生基础受回复倍率平加，0.2 表示额外增加 20% 受疗。 -->
    <healReceivedMultiplierOffset>0</healReceivedMultiplierOffset>

    <!-- 学生基础 EX 技能倍率平加，0.5 表示 EX 技能倍率提高到 150%。 -->
    <exSkillMultiplierOffset>0</exSkillMultiplierOffset>

    <!-- 攻击类型，作为属性克制矩阵的行。 -->
    <damageType>Through</damageType>

    <!-- 护甲类型，作为属性克制矩阵的列。 -->
    <defenseType>Explosion</defenseType>
  </li>
</modExtensions>
```

基础属性进入公式的位置：

```text
攻击平加 = 学生 attackFlat + BANW_RangedWeapon_Damage + 状态平加 + 阶级 attackFlat
攻击倍率 = 1 + 学生 attackPercent + BANW_FinalDamageMultiplier + 状态倍率 + 阶级 attackPercent
治疗平加 = 学生 healFlat + BANW_HealPowerBase + 状态平加 + 阶级 healFlat
治疗倍率 = 1 + 学生 healPercent + BANW_HealPowerMultiplier + 状态倍率 + 阶级 healPercent
受疗倍率 = BANW_HealReceivedMultiplier + 学生 healReceivedMultiplierOffset + 状态平加
EX倍率 = BANW_ExSkillMultiplier + 学生 exSkillMultiplierOffset + 状态平加
生命尺度 = (原始 HealthScale + 学生 healthFlat + 装备/属性生命平加 + 阶级 healthFlat)
        * (1 + 学生 healthPercent + 装备/属性生命百分比 + 阶级 healthPercent)
```

例如 Hediff 阶段加值：

```xml
<stages>
  <li>
    <statOffsets>
      <!-- 攻击平加 +30。 -->
      <BANW_RangedWeapon_Damage>30</BANW_RangedWeapon_Damage>

      <!-- 攻击倍率 +30%。 -->
      <BANW_FinalDamageMultiplier>0.3</BANW_FinalDamageMultiplier>
    </statOffsets>
  </li>
</stages>
```

## 暴击配置

技能段需要允许暴击：

```xml
<canCrit>true</canCrit>
```

角色暴击率：

```xml
<statBases>
  <!-- 0.3 表示 30% 暴击率。 -->
  <BANW_CriticalChance>0.3</BANW_CriticalChance>
</statBases>
```

角色暴击伤害：

```xml
<statBases>
  <!-- 2.0 表示暴击造成 200% 伤害。 -->
  <BANW_CriticalDamage>2.0</BANW_CriticalDamage>
</statBases>
```

结算顺序：

```text
先算基础伤害和攻击倍率
再算暴击
再算属性克制
```

## 攻击类型和护甲类型配置

攻击类型和护甲类型只配置在 `PawnKindDef.modExtensions` 的 `BattleBaseStatExtension`。

这是一套唯一入口，学生、敌人、普通 PawnKind 都按这个方式配置。不要在 `TraitDef` 里配置攻击类型或护甲类型，也不要把 `BaStudentDef.baStudentData.DamageType / DefenseType` 当成战斗配置入口；战斗克制结算不会读取它们。

示例：

```xml
<PawnKindDef ParentName="BANW_BasePawn">
  <defName>BANW_Nozomi</defName>

  <modExtensions>
    <li Class="BANWlLib.BattleSystem.BattleBaseStatExtension">
      <!-- 攻击类型，作为属性克制矩阵的行。 -->
      <damageType>Through</damageType>

      <!-- 护甲类型，作为属性克制矩阵的列。 -->
      <defenseType>Explosion</defenseType>
    </li>
  </modExtensions>
</PawnKindDef>
```

可用枚举：

```text
Explosion
Mysterious
Vibration
Through
Composite
```

代码读取位置：

```text
Source/BANWlLib/BattleSystem/BattleStatUtility.cs
TryGetDamageType
TryGetDefenseType
```

## 属性克制矩阵配置

配置位置：

```text
1.6/Defs/BattleSystem/BattleSystem.xml
```

配置类：

```text
BANWlLib.BattleSystem.DamageAffinityMatrixDef
```

示例：

```xml
<BANWlLib.BattleSystem.DamageAffinityMatrixDef>
  <defName>BANW_DamageAffinityMatrix_Default</defName>
  <label>BA属性克制矩阵</label>

  <!-- 没有攻击类型或护甲类型时使用。 -->
  <defaultMultiplier>1.0</defaultMultiplier>

  <rows>
    <li>
      <!-- 攻击类型。 -->
      <attackType>Through</attackType>
      <entries>
        <!-- Through 打 Explosion 护甲。 -->
        <li>
          <defenseType>Explosion</defenseType>
          <multiplier>1.0</multiplier>
        </li>

        <!-- Through 打 Through 护甲。 -->
        <li>
          <defenseType>Through</defenseType>
          <multiplier>2.0</multiplier>
        </li>
      </entries>
    </li>
  </rows>
</BANWlLib.BattleSystem.DamageAffinityMatrixDef>
```

技能段需要开启：

```xml
<applyAffinity>true</applyAffinity>
```

否则不会应用克制倍率。

## 克制伤害加成配置

克制加成是角色 Stat。

例如贯通克制加成 99%：

```xml
<statBases>
  <BANW_AffinityBonus_Through>0.99</BANW_AffinityBonus_Through>
</statBases>
```

规则：

```text
只有矩阵倍率 > 1.0 时生效。
最终克制倍率 = 矩阵倍率 * (1 + 对应攻击类型克制加成)
```

例子：

```text
Through 打 Through 护甲矩阵倍率 = 2.0
BANW_AffinityBonus_Through = 0.99

最终克制倍率 = 2.0 * (1 + 0.99) = 3.98
```

如果矩阵倍率是 1.0 或 0.5，克制加成不生效。

## 治疗配置

治疗段使用同一套段配置。

示例：

```xml
<li>
  <!-- true 表示这段是治疗。 -->
  <isHealing>true</isHealing>

  <!-- 固定治疗基础值。 -->
  <baseAmount>0</baseAmount>

  <!-- 治疗力倍率，2.0 表示 200% 治疗力。 -->
  <healPowerRatio>2.0</healPowerRatio>

  <!-- 治疗是否允许暴击。 -->
  <canCrit>true</canCrit>

  <!-- 治疗友方。 -->
  <affectFriendly>true</affectFriendly>

  <!-- 通常治疗不影响敌人。 -->
  <affectHostile>false</affectHostile>
</li>
```

当前真实治疗公式：

```text
治疗平加 = BANW_HealPowerBase
        + 叠层状态对 BANW_HealPowerBase 的加值
        + 阶级成长 healFlat

治疗倍率 = 1
        + BANW_HealPowerMultiplier
        + 叠层状态对 BANW_HealPowerMultiplier 的加值
        + 阶级成长 healPercent

最终治疗力 = 治疗平加 * 治疗倍率

基础治疗部分 = (baseAmount + 治疗平加) * 治疗倍率

倍率治疗部分 = 最终治疗力 * healPowerRatio

暴击前治疗 = 基础治疗部分 + 倍率治疗部分

最终治疗 = 暴击前治疗 * 目标受疗率
```

受疗率配置：

```xml
<statBases>
  <!-- 1.2 表示受到治疗为 120%。 -->
  <BANW_HealReceivedMultiplier>1.2</BANW_HealReceivedMultiplier>
</statBases>
```

## 直线穿透弹配置

直线穿透弹的伤害不写在 AbilityDef 的 `damages` 里，而是写在投射物 ThingDef 的扩展里。

配置类：

```text
BANWlLib.Projectiles.PiercingProjectileExtension
```

典型位置：

```text
1.6/Defs/ThingDef_Weapon/Highland.xml
```

示例：

```xml
<ThingDef ParentName="BaseBullet">
  <defName>BANC_Bullet_Nozomi_Train_Test</defName>
  <thingClass>BANWlLib.Projectiles.Projectile_PiercingArea</thingClass>

  <projectile>
    <!-- 原版字段仍需要合法 DamageDef，但实际统一伤害主要看扩展参数。 -->
    <damageDef>BANC_Damage_Nozomi_Train</damageDef>
    <damageAmountBase>0</damageAmountBase>
  </projectile>

  <modExtensions>
    <li Class="BANWlLib.Projectiles.PiercingProjectileExtension">
      <!-- 同一目标每隔多少 tick 可以再次受到伤害。 -->
      <damageIntervalTicks>6</damageIntervalTicks>

      <!-- 判定宽度。 -->
      <damageWidth>2.4</damageWidth>

      <!-- 判定长度。 -->
      <damageLength>44</damageLength>

      <!-- 是否免疫友伤。 -->
      <immuneFriendlyFire>true</immuneFriendlyFire>

      <!-- 固定基础值。 -->
      <baseAmount>0</baseAmount>

      <!-- 攻击力倍率，2.0 表示 200%。 -->
      <attackPowerRatio>2.0</attackPowerRatio>

      <!-- 是否暴击。 -->
      <canCrit>true</canCrit>

      <!-- 是否吃属性克制。 -->
      <applyAffinity>true</applyAffinity>

      <!-- 是否命中建筑。 -->
      <canHitBuilding>true</canHitBuilding>

      <!-- 是否影响敌人。 -->
      <affectHostile>true</affectHostile>

      <!-- 是否影响友方。 -->
      <affectFriendly>false</affectFriendly>

      <!-- 命中后沿弹道方向飞出的特效。 -->
      <directionalImpactEffect>BANW_Effecter_DirectionalImpact_Test</directionalImpactEffect>

      <!-- 方向特效是否在 Pawn 命中时触发。 -->
      <directionalImpactOnPawn>true</directionalImpactOnPawn>

      <!-- 方向特效是否在建筑命中时触发。 -->
      <directionalImpactOnBuilding>true</directionalImpactOnBuilding>

      <!-- 方向特效飞出速度。 -->
      <directionalImpactSpeed>8</directionalImpactSpeed>

      <!-- 方向特效向弹道前方偏移。 -->
      <directionalImpactOffsetForward>0.2</directionalImpactOffsetForward>

      <!-- 方向特效向上偏移。 -->
      <directionalImpactOffsetUp>0.4</directionalImpactOffsetUp>
    </li>
  </modExtensions>
</ThingDef>
```

## 脱手场地配置

脱手场地使用场地控制器 Thing。

配置类：

```text
BANWlLib.BattleSystem.BattleFieldControllerExtension
```

模板位置：

```text
1.6/Defs/BattleSystem/BattleSystem.xml
```

示例：

```xml
<ThingDef>
  <defName>BANW_BattleField_Damage_Template</defName>
  <thingClass>BANWlLib.BattleSystem.Thing_BattleFieldController</thingClass>
  <category>Mote</category>
  <tickerType>Normal</tickerType>

  <modExtensions>
    <li Class="BANWlLib.BattleSystem.BattleFieldControllerExtension">
      <!-- 场地持续时间。 -->
      <durationTicks>600</durationTicks>

      <!-- 每隔多少 tick 结算一次。 -->
      <intervalTicks>60</intervalTicks>

      <!-- 场地半径。 -->
      <radius>4.9</radius>

      <!-- true 表示生成时快照施法者属性。 -->
      <useCasterSnapshot>true</useCasterSnapshot>

      <!-- 每次脉冲在场地中心播放的特效。 -->
      <pulseEffecter>BANW_Effecter_A</pulseEffecter>

      <!-- 每次脉冲执行的动作。 -->
      <actions>
        <li>
          <baseAmount>0</baseAmount>
          <attackPowerRatio>1.2</attackPowerRatio>
          <damageDef>BANC_Damage_Nozomi_Train</damageDef>
          <penetration>0.25</penetration>
          <canCrit>true</canCrit>
          <applyAffinity>true</applyAffinity>
          <affectHostile>true</affectHostile>
          <affectFriendly>false</affectFriendly>
          <canHitBuilding>true</canHitBuilding>
        </li>
      </actions>
    </li>
  </modExtensions>
</ThingDef>
```

场地中心特效写：

```xml
<pulseEffecter>BANW_Effecter_A</pulseEffecter>
```

不要把场地中心特效写在 `actions` 里的 `effecterDef`，否则它会按命中目标触发。

## 叠层状态配置

配置类：

```text
BANWlLib.BattleSystem.HediffCompProperties_BattleStack
```

示例：

```xml
<HediffDef>
  <defName>BANW_BattleStack_Attack_Test</defName>
  <label>叠层攻击测试</label>
  <hediffClass>HediffWithComps</hediffClass>
  <comps>
    <li Class="BANWlLib.BattleSystem.HediffCompProperties_BattleStack">
      <!-- 叠层修改的 Stat。 -->
      <targetStat>BANW_FinalDamageMultiplier</targetStat>

      <!-- 最大层数。 -->
      <maxStacks>3</maxStacks>

      <!-- 重复施加是否刷新持续时间。 -->
      <refreshDurationOnApply>true</refreshDurationOnApply>

      <!-- 持续时间。 -->
      <durationTicks>1200</durationTicks>

      <!-- 到期是否移除。 -->
      <removeOnExpire>true</removeOnExpire>

      <!-- 每层对应值。 -->
      <stackValues>
        <li>0.30</li>
        <li>0.70</li>
        <li>1.00</li>
      </stackValues>
    </li>
  </comps>
</HediffDef>
```

含义：

```text
第一次施加：BANW_FinalDamageMultiplier +0.30
第二次施加：BANW_FinalDamageMultiplier +0.70
第三次施加：BANW_FinalDamageMultiplier +1.00
第四次施加：不再加层，只刷新持续时间
```

## 常用参数速查

```text
tick                         技能开始后第几 tick 触发该段
Delaytick                    主段触发后延迟多少 tick
damageAmount                 旧固定伤害字段，迁移期兼容
baseAmount                   固定基础值，当前会进入攻击/治疗属性缩放
attackPowerRatio             攻击力倍率，1.0 表示 100%
healPowerRatio               治疗力倍率，1.0 表示 100%
isHealing                    true 表示治疗，false 表示伤害
damageType                   RimWorld DamageDef
damageDef                    BattleActionConfig 中使用的 RimWorld DamageDef
penetration                  护甲穿透
canCrit                      是否允许暴击
applyAffinity                是否应用属性克制
affectHostile                是否影响敌人
affectFriendly               是否影响友方
isAttackBuilding             TickDamage/DamageSetting 是否命中建筑
canHitBuilding               BattleActionConfig 是否命中建筑
effecterDef                  技能段范围特效或按目标命中特效，取决于所在配置层
pulseEffecter                脱手场地每次脉冲的中心特效
directionalImpactEffect      直线弹命中后沿弹道方向飞出的特效
```

## 配置检查清单

技能没有伤害时检查：

```text
1. damageType 或 damageDef 是否存在。
2. baseAmount 和 attackPowerRatio 是否都为 0。
3. affectHostile / affectFriendly 是否符合目标阵营。
4. 建筑目标是否打开 isAttackBuilding 或 canHitBuilding。
5. 技能实际使用的 JobDef / projectileDef 是否就是你改的那个。
```

技能不吃克制时检查：

```text
1. 技能段 applyAffinity 是否为 true。
2. 施法者 PawnKindDef 的 BattleBaseStatExtension.damageType 是否配置。
3. 目标 PawnKindDef 的 BattleBaseStatExtension.defenseType 是否配置。
4. BattleSystem.xml 是否有对应 attackType 和 defenseType 的矩阵项。
5. 目标没有 defenseType 时，会走 defaultMultiplier。
```

技能特效不显示时检查：

```text
1. AOE 中心特效写在 TickDamage.effecterDef 或 DamageSetting.effecterDef。
2. 脱手场地中心特效写在 pulseEffecter。
3. 直线弹命中特效写在 directionalImpactEffect。
4. EffecterDef 是否存在，moteDef 是否存在，贴图路径是否正确。
5. 技能是否实际触发到对应 tick。
```
