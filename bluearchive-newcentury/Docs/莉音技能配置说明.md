# 莉音EX复制

技能配置位于 `1.6/Defs/SpecialSkills/Rio.xml`。

莉音对友军施放复制后，选中该友军使用“复制·EX”按钮。实际施法者是友军本体，射程、前摇、语音、特效、弹丸来源、攻击属性和护甲穿透均按其原技能执行。目标仍获得配置中的攻击支援增益。

## 阶段与角色机制

- 制服妮露处于二段时，默认复制“锐气攻击”，不会回到“大亢奋”入口；伤害读取本体现有锐气层数，施放也会增加本体层数。
- 妮露大亢奋到期或星野切换形态时，未使用的复制按钮跟随本体切换阶段。阶段切换时旧瞄准和旧排队施法会取消，复制机会仍保留。
- 爱丽丝的复制EX读取本体充能，发射后按原技能规则消耗本体充能。已满充能时不能绕过限制继续充能。
- 场地、无人机、被动触发等都由目标本体的原有技能逻辑处理，不创建默认阶段的独立角色状态。

## EX识别

读取目标实际持有的能力，只要带有 `BANWlLib.CostSystem.CompProperties_AbilityCost` 就识别为EX。基础费用或减费后的实际费用为0仍然是EX。无需角色白名单，不使用技能名称判断。

候选列表遵守原技能当前阶段的显隐条件；原技能冷却和当前COST不足不影响获得复制机会。默认优先当前角色专属测试EX，右键复制按钮可以选择其他当前阶段可见的COST技能。一个机会只能成功使用其中一个EX，切换候选不会增加使用次数。

`SpecialSkillKindExtension` 只负责绑定角色的 `profile`，不再声明 `copyableEx`。

## 费用与生命周期

复制能力拥有独立实例，从未冷却状态开始。基础COST先减1、最低0，再计算目标本体的固定及比例减费。复制入口的费用仍由莉音施法时支付。

成功施法才消耗机会并恢复莉音的复制入口；取消瞄准、技能目标失效或费用不足均保留机会。消费后复制按钮隐藏，能力托管的持续表现完成后再回收，已发出的弹丸、场地和增益继续执行。

一次性技能与原有EX使用独立按钮，多个莉音发放的机会分别保存。离图保留未使用机会；目标死亡、发放者死亡或发放状态被移除时回收未使用机会。存档保存目标能力与发放者之间的引用。
