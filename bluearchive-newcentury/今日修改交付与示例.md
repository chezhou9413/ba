# BANW XML 配置教程

这份文档只说明 XML 应该怎么写。示例中的 `BANW_Mika` 可以替换成目标学生的当前 ID。

## 基本命名规则

学生相关配置统一使用当前学生 ID 和当前 Kind ID，不再使用旧 race ID。

推荐保持这套命名：

- 学生 ID：`BANW_Mika`
- `PawnKindDef.defName`：`BANW_Mika`
- `BaStudentDef.defName`：`BANW_Mika_Student`
- 神名文字道具：`BANW_Mika_Proplevel`

抽卡池里写 `BaStudentDef.defName`，也就是 `BANW_Mika_Student`。

道具限制里有些字段名仍然叫 `<Race>`，但值要写当前学生 ID 或 `PawnKindDef.defName`，例如 `BANW_Mika`。

## 学生 Def

每个学生需要一个 `BANWlLib.BaDef.BaStudentDef`。`studentId` 是稳定学生 ID，`kindDef` 绑定实际生成的 `PawnKindDef`。

```xml
<?xml version="1.0" encoding="utf-8"?>
<Defs>
  <BANWlLib.BaDef.BaStudentDef>
    <defName>BANW_Mika_Student</defName>
    <label>未花</label>
    <studentId>BANW_Mika</studentId>
    <kindDef>BANW_Mika</kindDef>

    <BaStudentUI>
      <StudentAvatar>ManuaUI/Avatar/Mika</StudentAvatar>
      <StudentName>Auto</StudentName>
      <CharacterimagePath>ManuaUI/Live/Mika</CharacterimagePath>
      <BackgroundPath>ManuaUI/Bg/BG_Sany</BackgroundPath>
      <CharacterimageOffsetSize>1.4</CharacterimageOffsetSize>
      <CharacterimageOffsetX>5</CharacterimageOffsetX>
      <CharacterimageOffsetY>-50</CharacterimageOffsetY>
      <CharacterTypePath>ManuaUI/Type/Assault</CharacterTypePath>
      <CharacterStarCount>3</CharacterStarCount>
      <infotagImagePath1>ManuaUI/Type/输出</infotagImagePath1>
      <infotagImagePath2>ManuaUI/Type/前排</infotagImagePath2>
      <infotagImagePath3>ManuaUI/Type/贯通</infotagImagePath3>
      <infotagImagePath4>ManuaUI/Type/轻装甲</infotagImagePath4>
    </BaStudentUI>

    <baStudentData>
      <DamageType>Through</DamageType>
      <DefenseType>Explosion</DefenseType>
      <PosType>Henc</PosType>
      <StarCont>3</StarCont>
      <DraggableAudio>Common\Sounds\Fight\Mika</DraggableAudio>

      <GakaStudentThingData>
        <li>
          <key>Kami_Proplevel</key>
          <value>50</value>
        </li>
        <li>
          <key>BANW_Mika_Proplevel</key>
          <value>30</value>
        </li>
      </GakaStudentThingData>

      <UpGakaStudentThingData>
        <li>
          <key>Kami_Proplevel</key>
          <value>50</value>
        </li>
        <li>
          <key>BANW_Mika_Proplevel</key>
          <value>100</value>
        </li>
      </UpGakaStudentThingData>

      <OneGakaStudentThingData>
        <li>
          <key>BANW_Mika_Proplevel</key>
          <value>100</value>
        </li>
      </OneGakaStudentThingData>

      <avtTexPath>Gacha/Student/Mika</avtTexPath>
    </baStudentData>
  </BANWlLib.BaDef.BaStudentDef>
</Defs>
```

常用枚举值：

- `DamageType` / `DefenseType`：`Explosion`、`Mysterious`、`Vibration`、`Through`
- `PosType`：`Assist`、`Henc`、`Medical`、`Tank`、`Vehicle`

## PawnKind 配置

学生 PawnKind 的 `defName` 要和 `BaStudentDef.kindDef` 对上。

```xml
<?xml version="1.0" encoding="utf-8"?>
<Defs>
  <PawnKindDef ParentName="BANW_BasePawn">
    <defName>BANW_Mika</defName>
    <label>-未花-</label>
    <race>BANW_KivotosStudent</race>
    <combatPower>100</combatPower>
    <isFighter>true</isFighter>

    <modExtensions>
      <li Class="ChezhouLib.Extension.kindRule">
        <kindName>未花</kindName>
        <kindDesName>未花 未花 圣园</kindDesName>
        <Gender>Female</Gender>
      </li>

      <li Class="BANWlLib.KindStats.BANWKindStatExtension">
        <healthScaleOverride>12</healthScaleOverride>
        <worldCargoCapacityOffset>100</worldCargoCapacityOffset>
      </li>
    </modExtensions>
  </PawnKindDef>
</Defs>
```

如果原来的 `PawnKindDef` 已经有 `<modExtensions>`，只往里面追加新的 `<li Class="BANWlLib.KindStats.BANWKindStatExtension">`，不要再写第二个 `<modExtensions>` 节点。

`healthScaleOverride` 可以不写。不写时沿用种族生命值。

`worldCargoCapacityOffset` 可以不写。不写时这个 Kind 不额外增加世界地图货物能力。

## 学生星级组件

星级组件现在按学生 Kind 判断。基础学生种族的 comp 里建议开启 `requireStudentKind`，这样只有配置了 `BaStudentDef.kindDef` 的学生 Kind 会显示星级。

```xml
<li Class="BANWlLib.CompProperties_PawnProgressBarUI">
  <starInterval>0.5</starInterval>
  <showProgressBar>false</showProgressBar>
  <starProgressRatios>
    <li>0.0</li>
    <li>0.09</li>
    <li>0.33</li>
    <li>0.63</li>
    <li>1.0</li>
  </starProgressRatios>
  <starSize>28</starSize>
  <requireStudentKind>true</requireStudentKind>
  <starTexturePath>UI/StarIcon</starTexturePath>
</li>
```

如果某个 comp 只允许指定学生显示，可以写 `allowedPawnKinds`。

```xml
<li Class="BANWlLib.CompProperties_PawnProgressBarUI">
  <requireStudentKind>true</requireStudentKind>
  <allowedPawnKinds>
    <li>BANW_Mika</li>
    <li>BANW_Shiroko</li>
  </allowedPawnKinds>
</li>
```

## 抽卡池配置

`StudentList` 里写 `BaStudentDef.defName`，不要写 `PawnKindDef.defName`。

```xml
<threeStarPool>
  <Weight>2.0</Weight>
  <StudentList>
    <li>BANW_Mika_Student</li>
    <li>BANW_Shiroko_Student</li>
    <li>BANW_Rio_Student</li>
  </StudentList>
</threeStarPool>
```

UP 池也是一样：

```xml
<FESupthreeStarPool>
  <Weight>0.7</Weight>
  <StudentList>
    <li>BANW_Mika_Student</li>
  </StudentList>
</FESupthreeStarPool>
```

## 神名文字道具

神名文字的 `defName` 按当前学生 ID 命名为 `BANW_Mika_Proplevel`。

`CompProperties_UseEffectUpdateCustomInt` 的 `<Race>` 标签名保留，但值要写当前学生 ID 或 `PawnKindDef.defName`。

```xml
<ThingDef ParentName="BANW_Proplevel">
  <defName>BANW_Mika_Proplevel</defName>
  <label>未花的神名文字</label>
  <description>一种神秘的文字，蕴含着未知的力量。可以用来给学生升星。</description>

  <graphicData>
    <texPath>Prop/Proplevel/Mika</texPath>
    <graphicClass>Graphic_Single</graphicClass>
    <drawSize>1.0</drawSize>
  </graphicData>

  <comps>
    <li Class="CompProperties_Usable">
      <useJob>UseItem</useJob>
      <useLabel>使用未花的神名文字</useLabel>
      <useDuration>60</useDuration>
    </li>

    <li Class="BANWlLib.CompProperties_UseEffectUpdateCustomInt">
      <updateValue>1</updateValue>
      <Race>BANW_Mika</Race>
      <checkMaxLimit>true</checkMaxLimit>
      <checkMinLimit>true</checkMinLimit>
      <batchUseCount>
        <li>5</li>
        <li>10</li>
        <li>20</li>
        <li>50</li>
        <li>100</li>
        <li>150</li>
      </batchUseCount>
    </li>
  </comps>
</ThingDef>
```

## 活动报告书和状态道具

`ThingHediffCompProperties` 也使用 `<Race>` 限制目标学生。这里同样写当前学生 ID 或 `PawnKindDef.defName`。

```xml
<li Class="BANWlLib.comp.ThingHediffCompProperties">
  <hediffDefName>BANW_LevelTrait</hediffDefName>
  <Race>
    <li>BANW_Mika</li>
    <li>BANW_Shiroko</li>
    <li>BANW_Rio</li>
  </Race>
  <updateHediffSeverity>0.05</updateHediffSeverity>
  <batchUseCount>
    <li>5</li>
    <li>10</li>
    <li>20</li>
  </batchUseCount>
</li>
```

## 射程加值

射程使用原版 `StatDef` 配置，属性名是 `BANW_RangedWeapon_RangeOffset`。

`10` 表示最终非近战射程增加 10 格。近战 Verb 不会被这个属性提升。

武器、衣服、装备使用原版 `<equippedStatOffsets>`：

```xml
<equippedStatOffsets>
  <BANW_RangedWeapon_RangeOffset>10</BANW_RangedWeapon_RangeOffset>
</equippedStatOffsets>
```

Hediff 使用原版 `<statOffsets>`：

```xml
<HediffDef>
  <defName>BANW_Test_RangeBuff</defName>
  <label>射程提升</label>
  <stages>
    <li>
      <statOffsets>
        <BANW_RangedWeapon_RangeOffset>10</BANW_RangedWeapon_RangeOffset>
      </statOffsets>
    </li>
  </stages>
</HediffDef>
```

Trait 使用 `degreeDatas` 里的 `<statOffsets>`：

```xml
<TraitDef>
  <defName>BANW_Test_RangeTrait</defName>
  <degreeDatas>
    <li>
      <degree>0</degree>
      <label>远程强化</label>
      <statOffsets>
        <BANW_RangedWeapon_RangeOffset>10</BANW_RangedWeapon_RangeOffset>
      </statOffsets>
    </li>
  </degreeDatas>
</TraitDef>
```

## 生命值加值

生命值有三个配置入口：

- Kind 覆盖基础生命值：`healthScaleOverride`
- 平加生命值：`BANW_HealthScaleOffset`
- 百分比生命值：`BANW_HealthScalePercentOffset`

计算公式固定为：

```text
(Kind 覆盖值或原始生命值 + BANW_HealthScaleOffset) * (1 + BANW_HealthScalePercentOffset)
```

例如种族生命值是 `10`，Kind 写 `healthScaleOverride=12`，状态提供 `BANW_HealthScaleOffset=10` 和 `BANW_HealthScalePercentOffset=0.10`，最终生命值尺度是：

```text
(12 + 10) * 1.10 = 24.2
```

Kind 覆盖写在 `PawnKindDef` 的 `modExtensions` 里：

```xml
<li Class="BANWlLib.KindStats.BANWKindStatExtension">
  <healthScaleOverride>12</healthScaleOverride>
</li>
```

装备提供生命值加成：

```xml
<equippedStatOffsets>
  <BANW_HealthScaleOffset>10</BANW_HealthScaleOffset>
  <BANW_HealthScalePercentOffset>0.10</BANW_HealthScalePercentOffset>
</equippedStatOffsets>
```

Hediff 提供生命值加成：

```xml
<stages>
  <li>
    <statOffsets>
      <BANW_HealthScaleOffset>10</BANW_HealthScaleOffset>
      <BANW_HealthScalePercentOffset>0.10</BANW_HealthScalePercentOffset>
    </statOffsets>
  </li>
</stages>
```

百分比加成也写 offset。`0.10` 就是 `+10%`，不要写成 `10`。

## 世界地图货物能力

世界地图货物能力写在 `PawnKindDef` 的 `BANWKindStatExtension` 里。

`100` 表示这个 Kind 作为商队成员时，世界地图货物容量增加 `100kg`。

```xml
<li Class="BANWlLib.KindStats.BANWKindStatExtension">
  <worldCargoCapacityOffset>100</worldCargoCapacityOffset>
</li>
```

这个配置只影响世界地图商队和组建商队界面的货物能力，不影响小人在地图内的本地背包负重。

## 穿透抛射体

穿透弹的 `thingClass` 写 `BANWlLib.Projectiles.Projectile_PiercingArea`，并在 `modExtensions` 里挂 `PiercingProjectileExtension`。

```xml
<ThingDef ParentName="BaseBullet">
  <defName>BANW_Test_PiercingBullet</defName>
  <label>穿透弹</label>
  <thingClass>BANWlLib.Projectiles.Projectile_PiercingArea</thingClass>

  <graphicData>
    <texPath>Things/Projectile/Bullet_Big</texPath>
    <graphicClass>Graphic_Single</graphicClass>
    <drawSize>1.0</drawSize>
  </graphicData>

  <projectile>
    <damageDef>Bullet</damageDef>
    <damageAmountBase>10</damageAmountBase>
    <armorPenetrationBase>0.2</armorPenetrationBase>
    <speed>40</speed>
  </projectile>

  <modExtensions>
    <li Class="BANWlLib.Projectiles.PiercingProjectileExtension">
      <damageIntervalTicks>10</damageIntervalTicks>
      <damageWidth>10</damageWidth>
      <damageLength>10</damageLength>
      <immuneFriendlyFire>true</immuneFriendlyFire>
      <startDrawScale>0.3</startDrawScale>
      <endDrawScale>2.0</endDrawScale>
      <fadeInTicks>5</fadeInTicks>
      <fadeOutTicks>10</fadeOutTicks>
    </li>
  </modExtensions>
</ThingDef>
```

参数含义：

- `damageIntervalTicks`：飞行中每多少 tick 造成一次范围伤害。
- `damageWidth`：垂直于飞行方向的宽度，单位是格。
- `damageLength`：沿飞行方向的长度，单位是格。
- `immuneFriendlyFire`：`true` 时跳过友军。
- `startDrawScale`：飞行开始时贴图缩放。
- `endDrawScale`：飞行结束时贴图缩放。
- `fadeInTicks`：淡入 tick 数，`0` 表示不淡入。
- `fadeOutTicks`：淡出 tick 数，`0` 表示不淡出。

武器或技能的 Verb 指向这个抛射体：

```xml
<verbs>
  <li>
    <verbClass>Verb_LaunchProjectile</verbClass>
    <defaultProjectile>BANW_Test_PiercingBullet</defaultProjectile>
    <range>30</range>
    <warmupTime>1.0</warmupTime>
    <ticksBetweenBurstShots>10</ticksBetweenBurstShots>
    <burstShotCount>1</burstShotCount>
  </li>
</verbs>
```

`damageWidth=10`、`damageLength=10` 表示飞行中按 `10x10` 的矩形范围检测敌人。抛射体遇到天然岩墙、建造墙、关闭门这类完整阻挡物会停下，开放门不阻挡。

## 不要再写的旧配置

不要再写这些旧字段或旧命名：

```xml
<legacyRaceDefName>...</legacyRaceDefName>
```

```xml
<allowedRaces>
  <li>BANW_Mika_race</li>
</allowedRaces>
```

```xml
<StudentList>
  <li>BANW_Mika</li>
</StudentList>
```

```xml
<defName>BANW_Mika_race_Proplevel</defName>
```

正确写法分别是：

```xml
<studentId>BANW_Mika</studentId>
<kindDef>BANW_Mika</kindDef>
```

```xml
<allowedPawnKinds>
  <li>BANW_Mika</li>
</allowedPawnKinds>
```

```xml
<StudentList>
  <li>BANW_Mika_Student</li>
</StudentList>
```

```xml
<defName>BANW_Mika_Proplevel</defName>
```

## 配置检查清单

- `BaStudentDef.defName` 使用 `BANW_xxx_Student`。
- `BaStudentDef.studentId` 和 `BaStudentDef.kindDef` 都写当前学生 ID，例如 `BANW_Mika`。
- `PawnKindDef.defName` 与 `BaStudentDef.kindDef` 一致。
- 抽卡池 `StudentList` 写 `BANW_xxx_Student`。
- 神名文字道具写 `BANW_xxx_Proplevel`。
- 道具 comp 的 `<Race>` 值写当前学生 ID，不写旧 race ID。
- 星级组件使用 `<requireStudentKind>true</requireStudentKind>`。
- 需要指定学生时使用 `<allowedPawnKinds>`，不使用 `<allowedRaces>`。
- 射程加值写 `BANW_RangedWeapon_RangeOffset`，数值 `10` 就是加 10 格。
- 生命平加写 `BANW_HealthScaleOffset`。
- 生命百分比写 `BANW_HealthScalePercentOffset`，`0.10` 就是加 10%。
- Kind 覆盖生命和世界货物能力写 `BANWlLib.KindStats.BANWKindStatExtension`。
- 穿透弹写 `BANWlLib.Projectiles.Projectile_PiercingArea` 和 `BANWlLib.Projectiles.PiercingProjectileExtension`。
- XML 声明保持 `<?xml version="1.0" encoding="utf-8"?>`。
