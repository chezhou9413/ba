# Unity 贴图工程

本目录是独立的 Unity 工程，与 `bluearchive-newcentury` Mod 目录并列。使用 Unity Hub 添加本目录即可打开；编辑器版本见 `ProjectSettings/ProjectVersion.txt`。

图片位置、XML 路径对应关系及构建命令见[贴图路径与 Unity 工程说明](../贴图路径与Unity工程说明.md)。只查看图片时，不需要安装 Unity。

`Assets`、对应 `.meta`、`Packages`、`ProjectSettings` 和构建脚本随 Git 保存；`Library`、`Logs`、`Build`、`UserSettings` 等本机生成目录不纳入 Git。
