# 1024 小人贴图包

本目录提供 BA 小人贴图的 Windows 1024 分辨率 AssetBundle。图片取自仓库同级目录 `../UnityProject` 中的永久小人源图，贴图路径与默认包一致。源图定位方法见[贴图路径与 Unity 工程说明](../贴图路径与Unity工程说明.md)。

**直接覆盖同名的 `banw_pawns_win` 即可切换到 1024 版本，不需要修改 XML、角色 Def 或开启额外设置。**

## 安装

1. 退出 RimWorld。
2. 备份 Mod 的 `1.6/AssetBundles/banw_pawns_win` 与同名 `.manifest`。
3. 用本目录中的 `banw_pawns_win` 和 `banw_pawns_win.manifest` 替换这两个文件。
4. 重新启动游戏。

恢复默认画质时，将备份的 512 包放回即可。无需同时加载两份小人包，也不需要复制构建工具或使用说明到游戏。

小人源图在 Unity 工程中维护。`Common/Textures/Pawns` 中的同名散图会优先于 AB，因此使用替换包切换画质时，Mod 中应只保留打包后的资源，不再放入这些同名散图。

## 图片规格

- 分辨率上限：1024 × 1024；大部分源图原本就是此尺寸。
- 小于上限的图片保持原尺寸，更大的图片按导入上限缩小。
- Windows 64 位，DXT5 纹理压缩，LZ4 包压缩，不生成 mipmap。
- 相同格式下，1024 × 1024 贴图的像素内存约为 512 × 512 的四倍；文件体积还取决于内容压缩率。

UI 图片和特效包不包含在本目录中。

## 重新构建

在 PowerShell 中进入本目录，运行 `构建1024贴图包.ps1`。使用 Unity 2022.3.35f1c1（以 `../UnityProject/ProjectSettings/ProjectVersion.txt` 为准）。脚本自动定位相邻的 `UnityProject`，只需指定本机编辑器路径，也可通过 `UNITY_EDITOR_PATH` 环境变量设置。

```powershell
& '.\构建1024贴图包.ps1' -UnityEditor '你的Unity安装目录/Editor/Unity.exe'
```

构建过程会临时使用 1024 导入设置，结束后还原原有设置，只更新本目录的包文件。Mod 工程中的默认 512 包保持不变。

需要两份包同步更新时，添加 `-Update512`：

```powershell
& '.\构建1024贴图包.ps1' -UnityEditor '你的Unity安装目录/Editor/Unity.exe' -Update512
```

此模式使用完全相同的角色素材，先更新仓库内 `bluearchive-newcentury/1.6/AssetBundles` 的 512 包，再生成本目录的 1024 包。两个包文件同名、资源路径相同，只需替换文件即可切换清晰度；构建不会部署到游戏安装目录。

仓库中仍保留的角色散图会先合入 Unity 源目录，因此角色新增或同名素材更新也会进入包内；Unity 中的其他角色源图不会被清理。

日志位于 `../UnityProject/Logs/build-Pawns1024.log`；同时更新两份包时为 `build-PawnsBoth.log`。中间产物位于 `../UnityProject/Build/AssetBundles`。日志、缓存与中间产物由 Git 忽略，包文件、清单、说明、构建脚本及 Unity 素材源文件纳入 Git 管理。
